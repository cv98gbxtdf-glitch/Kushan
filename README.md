# Kushan

A modular Roblox exploit framework providing universal combat utilities (ESP, hitbox extender) and game-specific automation for supported Roblox games.

## Features

- **ESP** — Player spotting with highlights, health indicators, distance display, and visualization options (boxes, tracers, arrows, skeleton)
- **Hitbox Extender** — Enlarged player hitboxes with adjustable size and transparency
- **Game Automation** — Mission completion, rank filtering, and game-specific features for supported titles
